Since WSL2 runs in a separate internal network, your phone on the local WiFi (e.g., `192.168.x.x`) cannot directly reach the Metro bundler running inside WSL (e.g., `172.x.x.x`). You need to bridge this gap by setting up port forwarding on Windows and telling Expo to use your Windows Host IP.

Follow these steps:

#### 1. Identify your IP Addresses
Run these commands to find your current IPs:
- **In WSL:** `hostname -I` (e.g., `172.25.216.228`)
- **In Windows (PowerShell):** `Get-NetIPAddress -AddressFamily IPv4 | Where-Object { $_.InterfaceAlias -notmatch 'vEthernet' -and $_.AddressState -eq 'Preferred' -and $_.IPAddress -notlike '127.*' } | Select-Object -ExpandProperty IPAddress` (e.g., `192.168.4.34`)

#### 2. Configure Windows Port Forwarding (Run as Admin)
Open PowerShell as **Administrator** and run the following commands (replace `<WSL_IP>` with your WSL IP from step 1):

```powershell
# Forward Metro port (8081) from Windows to WSL
netsh interface portproxy add v4tov4 listenport=8081 listenaddress=0.0.0.0 connectport=8081 connectaddress=<WSL_IP>

# Open Windows Firewall for port 8081
New-NetFirewallRule -DisplayName "Expo WSL" -Direction Inbound -LocalPort 8081 -Protocol TCP -Action Allow
```

*Note: If you ever change networks or restart WSL, the WSL IP might change, and you'll need to update the `connectaddress`.*

#### 3. Set Expo Hostname in WSL
Before starting Expo, set the `REACT_NATIVE_PACKAGER_HOSTNAME` environment variable to your **Windows Host IP** (e.g., `192.168.4.34`). This ensures the QR code generated by Expo uses the IP reachable by your phone.

In your WSL terminal:
```bash
export REACT_NATIVE_PACKAGER_HOSTNAME=192.168.4.34
yarn start
```

#### 4. Verification
1. Ensure your phone and PC are on the same WiFi.
2. Scan the QR code with the Expo Go app. It should now connect to `192.168.4.34:8081`, which Windows will forward to your WSL instance.

### Summary of what was done
- Identified the networking barrier between WSL2 and the local WiFi.
- Used `netsh interface portproxy` to route traffic from the Windows host to the WSL2 VM.
- Configured Windows Firewall to allow incoming connections on the Metro port (8081).
- Used `REACT_NATIVE_PACKAGER_HOSTNAME` to force Expo to advertise the Windows Host IP instead of the internal WSL IP.
