# Global Junie Guidelines

- **Code Style Consistency**: Always match the existing codebase's style (indentation, naming, file layout).
- **Non-Interactive Execution**: Use only non-interactive commands.
- **Minimal Changes**: Avoid over-engineering; implement only what's required by the task.
- **Verification**: Always verify changes by running relevant tests or checking outputs.
- **Path Handling**: On Windows, use `\` for paths and `;` to chain PowerShell commands.
- **Environment**: You are operating in a JetBrains IDE environment. Do not suggest VS Code specific files or extensions.
